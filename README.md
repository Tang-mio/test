# 排七計錢

翻開各家的蓋牌點一點，馬上算出這局誰贏、誰付誰多少，也能把每局記進累計帳。

直接用瀏覽器打開 `index.html` 就能用，不需要安裝任何東西。

## 怎麼用

畫面是手機優先設計，一個人用一支手機就能很快把一局記完：

1. 第一次用先按「名字・規則」，填好東、南、西、北家的名字，確認每點金額和倍數。
2. 按「♠7 先出」標出這局誰先出牌。
3. 上方四個分頁是四家，選中的那家用底部的牌面鍵盤點他的蓋牌；點錯按「退一張」，或點上面的牌移除。
4. 按「下一家」換人，脫手的人沒有牌就直接跳過；脫手且最後打出 7 的，勾「尾張七」。
5. 每家的點數和輸贏會即時顯示在分頁上，鍵盤上方是本局贏家和收多少；下面有每個人付多少的算式。
6. 按「記入，下一局」存進累計帳並清空蓋牌。在「累計帳」可以看總輸贏，也能複製結算文字貼到群組。

在電腦上也可以直接打字：A、2–6、8、9、0（代表 10）、J、Q、K；退格鍵退一張，→ 或 Enter 換下一家。

### 多支手機同一局

在 claude.ai 打開發佈後的頁面時，資料存在頁面的共用資料庫裡，每支手機打開同一個連結就是同一局：

- `seats/0`～`seats/3`：每家一份文件（名字、蓋牌、尾張七），不同手機輸入不同家不會互相覆蓋
- `table/meta`：規則設定、誰拿 ♠7、下一局編號
- `ledger/rNNNNN`：每局結果；兩支手機同時按「記入」會寫到同一份文件，不會重複記帳

要能輸入需要頁面的編輯權限；只有檢視權限的人會即時看到同一局，但不能改。沒有 Claude 帳號的人無法同步，建議一支手機記帳，再用「複製結算文字」分享。

直接用瀏覽器打開 `index.html`（不在 claude.ai 裡）時是單機模式，資料存在這台裝置的 localStorage。

## 規則

### 基本玩法

- 一副牌 52 張，四人各 13 張。拿到 ♠7 的人先出，第一張一定是 ♠7。
- 依座位順序輪流，每次出一張：任何花色的 7，或接在桌上同花色的龍頭尾（7 往上接 8…K，往下接 6…A）。
- 有牌能出就一定要出；真的沒牌能出，才挑一張牌面朝下蓋起來。
- 7 一定能出，所以永遠不會被蓋（鍵盤上沒有 7）。

### 點數

A = 1，2～10 照牌面，J = 11，Q = 12，K = 13。蓋牌點數加總，越少越好。

### 勝負（由上往下比）

1. 十三蓋：13 張全蓋
2. 尾張七：脫手，且最後打出的是 7
3. 脫手：一張都沒蓋
4. 蓋牌點數少
5. 蓋牌張數少
6. 出牌順序早（從拿 ♠7 的人開始數）

### 倍數（預設值，都可以在「規則設定」調整或關掉）

| 牌型 | 條件 | 倍數 |
| --- | --- | --- |
| 脫手 | 贏家一張都沒蓋 | ×2 |
| 尾張七 | 贏家脫手，最後一張打出 7（取代脫手的 ×2） | ×4 |
| 十三蓋 | 贏家 13 張全蓋，反敗為勝 | ×5 |
| 爆點 | 輸家蓋牌超過 40 點（41 點起），只加在這位輸家身上 | ×2 |

贏家的倍數和輸家自己的爆點倍數相乘。例如贏家脫手、你又爆點，就是 ×4。

### 計錢

只有贏家收錢，三位輸家各自付給贏家：

- 付全額（預設）：自己的點數 × 倍數 × 每點金額
- 付差額：（自己的點數 − 贏家的點數）× 倍數 × 每點金額；十三蓋的贏家以 0 點計

### 範例

每點 $1、付全額。東家脫手；南家蓋 K Q 9（34 點）；西家蓋 A 3 5 2（11 點）；北家蓋 K K J 10 8（55 點，爆點）。

| 輸家 | 算式 | 付給東家 |
| --- | --- | --- |
| 南家 | 34 × 脫手 2 | $68 |
| 西家 | 11 × 脫手 2 | $22 |
| 北家 | 55 × 脫手 2 × 爆點 2 | $220 |

東家共收 $310。

## 檔案

- `index.html`：計算機頁面
- `paiqi.js`：計分邏輯（比牌、倍數、誰付誰多少），瀏覽器和 Node 都能載入
- `test/paiqi.test.js`：計分規則的測試，用 `npm test` 執行（Node 18 以上）
- `fonts/`：獅尾肉丸子集字型（一般、粗體）與授權 `OFL.txt`
- `tools/subset-font.js`：TrueType 子集化工具，只留指定的字，輸出 WOFF
- `tools/build-fonts.js`：重新產生 `fonts/` 裡的字型
- `tools/build-artifact.js`：把頁面、計分程式和字型打包成單一 HTML 檔

## 字體

整頁使用[獅尾肉丸](https://github.com/max32002/swei-meatball)（Max 以思源宋體改造，SIL Open Font License 1.1），金額數字用 IBM Plex Mono。
完整字型每套將近 19 MB，所以只收錄頁面上用到的字加上 Big5 常用字（5401 字），每套約 1.3 MB；常用字以外的罕用字會改用系統的宋體顯示。

改了頁面文字之後，要重新產生字型（先從獅尾肉丸的 GitHub 下載 `CJK TC/SweiMeatballCJKtc-Regular.ttf` 和 `-Bold.ttf`）：

```sh
node tools/build-fonts.js <TTF 所在資料夾>
```
