# 牌桌計錢

家裡打牌用的計錢工具，包含排七、麻將、21 點三種。一支手機就能記帳：輸入這局的結果，馬上算出誰付誰多少，每局記進累計帳，最後一起結算。

直接用瀏覽器打開 `index.html` 就能用，不需要安裝任何東西。

## 怎麼用

打開後先到首頁選「今天打什麼」。玩家名字三種遊戲共用，按「改名字」就能設定；點自己的名字標成「我」（只存在這支手機）。排七用前四位，依序坐東、南、西、北；麻將誰坐哪要在麻將頁抓位；21 點最多 8 人。
每個遊戲頁的上方有「本局／累計帳／規則」三個分頁，底部固定顯示這局的結算和「記入」按鈕。

### 排七

1. 按「♠7 先出」標出這局誰先出牌。
2. 上方四個分頁是四家，選中的那家用底部的牌面鍵盤點他的蓋牌；點錯按「退一張」，或點上面的牌移除。
3. 按「下一家」換人，脫手的人沒有牌就直接跳過；脫手且最後打出 7 的，勾「尾張七」。
4. 按「記入，下一局」。

電腦上也可以直接打字：A、2–6、8、9、0（代表 10）、J、Q、K；退格鍵退一張，→ 或 Enter 換下一家。

### 麻將

麻將頁用牌桌的樣子排座位，牌桌會轉成你坐在下面：右邊是下家、對面是對家、左邊是上家（東 → 南 → 西 → 北 逆時針輪）。

**抓位**：第一次進麻將，或從首頁進來時已經超過 3 小時沒抓位，會先請你抓位（上次坐的位置會留著）；打到一半要重抓，按牌桌上方的「重新抓位」。

- 在「我抓到」點你抓到的風，接著會依序問下家、對家、上家坐誰，點名字就好。
- 也可以直接點牌桌上的位置，再選坐在那裡的人；選到已經坐在別處的人，兩個人會對調。
- 還沒在首頁選自己是誰的話，抓位時會先問你是誰。誰坐哪大家共用；「我」只存在這支手機，所以每支手機都會轉成自己坐下面。
- 按「抓位完成」才能開始輸入。累計帳記在玩家身上，換位置不影響帳。

1. 確認莊家和連莊次數（記完一把會自動換莊或連莊）；要換莊家就按「換莊家」再點牌桌上的人。
2. 在牌桌上點誰胡；沒人胡就按「流局」。
3. 選自摸或放槍；放槍就在牌桌上再點是誰打的。點胡的人可以取消重選。
4. 點選牌型算台數，表上沒有的台數用「＋／−」加減。每個人收、付多少會直接顯示在牌桌的座位上。
5. 按「記入，下一把」。

**將、圈、把**：一把是一手牌；莊家從起莊輪一輪、回到起莊是一圈（連莊、流局不算新的一圈）；東風、南風、西風、北風四圈是一將。標題會顯示現在打到哪，例如「東風南／第 1 將」：東風圈、第二位莊家（起莊算東）。北風北的莊家下莊，這將就打完了，會自動進下一將並重新抓位，可以在抓位時選這將誰起莊。開始記帳時已經打到一半，在「名字・規則 → 牌局進度」改第幾將、圈風和起莊。

### 21 點

1. 點選這局的莊家。
2. 每位閒家確認下注金額（會保留到下一局），有加倍就勾「加倍」。
3. 開牌後點每位閒家的結果：贏、輸、平手、黑傑克、過五關、投降。
4. 按「記入，下一局」。

### 累計帳

可以看全部遊戲加總，也可以只看某一種。「複製結算文字」可以貼到群組。

### 多支手機同一局

在 claude.ai 打開發佈後的頁面時，資料存在頁面的共用資料庫裡，每支手機打開同一個連結就是同一個牌桌：

- `seats/0`～`seats/3`：排七每家的蓋牌，以及前四位玩家的名字
- `table/meta`：排七規則、誰拿 ♠7、下一局編號
- `table/roster`：第 5～8 位玩家的名字
- `table/mahjong`：麻將規則、抓位（誰坐東南西北）、第幾將和圈風、莊家、連莊、這把的輸入
- `table/blackjack`：21 點規則、莊家、下注與結果
- `ledger/{id}`：每局結果；id 由遊戲和局號組成，兩支手機同時按「記入」會寫到同一份，不會重複記帳

要能輸入需要頁面的編輯權限；只有檢視權限的人會即時看到，但不能改。沒有 Claude 帳號的人無法同步，建議一支手機記帳，再用「複製結算文字」分享。

直接用瀏覽器打開 `index.html`（不在 claude.ai 裡）時是單機模式，資料存在這台裝置的 localStorage；舊版排七的資料會自動搬過來。

## 規則

各家規矩不一樣，倍數、底、台、下注都可以在「名字・規則」裡改。

### 排七

- 一副牌 52 張，四人各 13 張。拿到 ♠7 的人先出，第一張一定是 ♠7。
- 依座位順序輪流，每次出一張：任何花色的 7，或接在桌上同花色的龍頭尾（7 往上接 8…K，往下接 6…A）。
- 有牌能出就一定要出；真的沒牌能出，才挑一張牌面朝下蓋起來。7 一定能出，所以永遠不會被蓋。
- 點數：A = 1，2～10 照牌面，J = 11，Q = 12，K = 13。蓋牌點數加總，越少越好。
- 勝負由上往下比：十三蓋 > 尾張七 > 脫手 > 點數少 > 張數少 > 出牌順序早（從拿 ♠7 的人開始數）。

| 牌型 | 條件 | 倍數 |
| --- | --- | --- |
| 脫手 | 贏家一張都沒蓋 | ×2 |
| 尾張七 | 贏家脫手，最後一張打出 7（取代脫手的 ×2） | ×4 |
| 十三蓋 | 贏家 13 張全蓋，反敗為勝 | ×5 |
| 爆點 | 輸家蓋牌超過 40 點（41 點起），只加在這位輸家身上 | ×2 |

只有贏家收錢。付全額（預設）：自己的點數 × 倍數 × 每點金額；付差額：（自己的點數 − 贏家的點數）× 倍數 × 每點金額，十三蓋的贏家以 0 點計。

例：每點 $1、付全額。東家脫手；南家蓋 34 點付 $68；西家蓋 11 點付 $22；北家蓋 55 點爆點，付 55 × 2 × 2 = $220。東家共收 $310。

### 麻將（台灣十六張）

- 每位付錢的人付「底 + 台數 × 每台」，預設底 $50、每台 $20。
- 自摸：三家都付；放槍：只有放槍的人付。
- 莊家台：莊家胡牌，或莊家付錢時，預設多算 1 台，每連莊一次再加 2 台（連 N 拉 N）。兩個閒家之間的支付不算莊家台。
- 換莊：莊家胡或流局就連莊；閒家胡就由下一家當莊。
- 將與圈：莊家輪一輪、回到起莊是一圈；東風、南風、西風、北風四圈是一將。北風北的莊家下莊就進下一將。
- 北部打法／南部打法：在「名字・規則」可以一鍵套用，只改規則和台數表，底和每台不變，套用後還能再改。
  - 北部打法（預設）：有花牌；邊張、中洞、單吊 1 台；風牌要對到圈風或門風；莊家 1 台、每連莊加 2 台；碰碰胡 4 台；不限台。
  - 南部打法（無花）：不打花牌；邊張、中洞、單吊不算台；見字有台，風牌刻子不用對位；莊家沒連莊不算台，連 N 拉 N 共 2N+1 台；碰碰胡 2 台；滿台 4 台。
  - 南部打法各家差很多（只算 2N、混一色也算 2 台、滿台含不含連莊台等），照自家習慣在台數表裡調整。
- 玩花牌：可以設定有沒有玩花牌（預設有）。不玩花牌時，正花、花槓、八仙過海、七搶一不會出現，也不算台。
- 限台：可以設定一把最多算幾台（預設不限），並選擇莊家台要算在上限內，或另外加在上限之外。
- 台數表可以自己改：每種台型的台數都能改、不用的可以關掉，也能新增自己家的台型；莊家台、每連莊加幾台、自摸、門清自摸合計也都能改。這些在「名字・規則 → 台數表」。
- 預設台數依常見算法：自摸 1、門清 1（門清自摸合計 3）、獨聽 1、平胡 2、半求 1、全求 2、槓上開花 1、海底撈月 1、河底撈魚 1、搶槓 1、三元牌每組 1、圈風 1、門風 1、正花每張 1、花槓 2、碰碰胡 4、三暗刻 2、四暗刻 5、五暗刻 8、混一色 4、清一色 8、字一色 16、小三元 4、大三元 8、小四喜 8、大四喜 16、八仙過海 8、七搶一 8、天胡 16、地胡 16、人胡 8。

例：東家當莊連 1，南家自摸 3 台。東家付 50 + (3 + 3) × 20 = $170，西家、北家各付 50 + 3 × 20 = $110，南家共收 $390。

限台的例子：限 10 台、莊家台另外加。東家當莊連 2（莊家台 5），南家自摸算出 13 台。西家、北家各付 50 + 10 × 20 = $250，東家付 50 + (10 + 5) × 20 = $350。

### 21 點

- 一人當莊家，閒家各自和莊家比，越接近 21 越好，超過 21 爆牌。A 算 1 或 11，J、Q、K 算 10。
- 贏：莊家照下注賠；輸（含爆牌）：莊家收下注；平手：不算。
- 黑傑克（頭兩張 A 加 10 點牌）賠 1.5 倍；過五關（五張沒爆）賠 2 倍；投降輸一半。
- 加倍：下注變兩倍，贏、輸、平手、過五關都照兩倍算；黑傑克和投降不受影響。
- 莊家的輸贏是所有閒家輸贏加起來的相反數。

例：每人下注 $100。南家黑傑克 +$150，西家加倍贏 +$200，北家爆牌 −$100，莊家共賠 $250。

## 檔案

- `index.html`：頁面與樣式
- `app/core.js`：共用核心（狀態、儲存、同步、首頁、累計帳、名字與規則面板）
- `app/paiqi-ui.js`、`app/mahjong-ui.js`、`app/blackjack-ui.js`：三個遊戲的畫面
- `paiqi.js`、`mahjong.js`、`blackjack.js`：三個遊戲的計分邏輯，瀏覽器和 Node 都能載入
- `test/`：計分規則的測試，用 `npm test` 執行（Node 18 以上）
- `fonts/`：獅尾肉丸子集字型（一般、粗體）與授權 `OFL.txt`
- `tools/subset-font.js`：TrueType 子集化工具，只留指定的字，輸出 WOFF
- `tools/build-fonts.js`：重新產生 `fonts/` 裡的字型
- `tools/build-artifact.js`：把頁面、程式和字型打包成單一 HTML 檔

## 字體

整頁使用[獅尾肉丸](https://github.com/max32002/swei-meatball)（Max 以思源宋體改造，SIL Open Font License 1.1），金額數字用 IBM Plex Mono。
完整字型每套將近 19 MB，所以只收錄頁面上用到的字加上 Big5 常用字（5401 字），每套約 1.3 MB；常用字以外的罕用字會改用系統的宋體顯示。

改了頁面文字之後，要重新產生字型（先從獅尾肉丸的 GitHub 下載 `CJK TC/SweiMeatballCJKtc-Regular.ttf` 和 `-Bold.ttf`）：

```sh
node tools/build-fonts.js <TTF 所在資料夾>
```
